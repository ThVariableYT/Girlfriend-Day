# **💕 Girlfriend Day Web App**

> A romantic, interactive, and customizable web application to celebrate National Girlfriend Day, anniversaries, or special relationship milestones\!

## **📌 Overview**

**Girlfriend-Day** is a sweet, interactive web application built using modern web standards. Designed to surprise your partner, this project features interactive prompts, photo galleries, background music, floating heart animations, and custom love notes to create a memorable digital gift.

## **✨ Key Features**

* **💖 Interactive Surprises & Prompts:** Playful interactive elements including choice popups ("Yes" / runaway "No" button interactions) or reveal cards.  
* **📸 Memory Gallery:** Photo display/slideshow layout showcasing special moments, dates, and shared memories.  
* **💌 Digital Love Letter:** Interactive modal card to share personal notes and heartfelt messages.  
* **🎵 Integrated Music Player:** Ambient background music player controls to set a romantic mood.  
* **🌸 Smooth Visual Animations:** Floating hearts, smooth CSS transitions, floating particles, and aesthetic glassmorphism UI design.  
* **📱 Responsive & Mobile-Friendly:** Fully optimized across desktop, tablet, and mobile screens.  
* **⚡ Lightweight Performance:** Native frontend stack—fast loading with zero external heavy frameworks required.

## **🛠️ Tech Stack**

| Technology | Purpose |
| :---- | :---- |
| **HTML5** | Web page structure and semantic markup |
| **CSS3** | Glassmorphism UI, flexbox/grid layout, custom keyframe animations |
| **JavaScript (ES6+)** | Interactive logic, DOM manipulation, floating particle physics, and audio controls |
| **Google Fonts / Icons** | Romantic typography and UI iconography |

## **🚀 Getting Started**

Follow these steps to run the web application locally on your machine:

### **Prerequisites**

* Any modern web browser (Google Chrome, Firefox, Edge, Safari).  
* [Git](https://git-scm.com/) (optional, for cloning).

### **Local Setup**

1. **Clone the repository:**  
   git clone https://github.com/ThVariableYT/Girlfriend-Day.git

2. **Navigate to the project folder:**  
   cd Girlfriend-Day

3. **Launch the application:**  
   * Double-click index.html to open it in your web browser, OR  
   * Open with VS Code and run using the **Live Server** extension.

## **🎨 Customization Guide**

Make this project uniquely yours by personalizing the content:

1. **Edit Text & Love Letters:**  
   * Open index.html and modify the text in heading and paragraph tags to customize your personal message and story.  
2. **Replace Gallery Images:**  
   * Add your photos into the assets/images/ directory.  
   * Update the src attribute in the HTML image tags to match your file names.  
3. **Change Background Music:**  
   * Place your partner's favorite song (.mp3) in assets/audio/.  
   * Update the \<audio src="..."\> source attribute in index.html or script.js.

## **🌐 Deploying & Sharing**

To share the web application with your partner via a public link, deploy it for free using **GitHub Pages**:

1. Push your changes to your GitHub repository.  
2. Navigate to repository **Settings** \-\> **Pages**.  
3. Under **Branch**, choose main (or master) and select folder /root.  
4. Click **Save**. Your site will be published at:  
   https://ThVariableYT.github.io/Girlfriend-Day/
